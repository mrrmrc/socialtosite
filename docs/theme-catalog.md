# Catalogo temi All Social To Web

Il catalogo contiene 100 temi ottenuti combinando 10 famiglie strutturali originali con 10 palette curate. Non contiene HTML, CSS, immagini o asset copiati da marketplace commerciali.

## Struttura

- 10 famiglie: editoriale, creator, cinematico, umano, business, professionale, hospitality, journal, portfolio e boutique.
- 10 palette per ogni famiglia.
- Ogni tema salva font, palette, stile UI, ricetta del layout e modello strutturale nel campo `site_ai_data`.
- L'anteprima usa gli stessi dati del tema che verranno salvati, quindi ciò che il cliente vede corrisponde al rendering pubblico applicato.

## Provenienza e licenze

L'implementazione grafica è originale di All Social To Web e usa pattern di web design generali. Il campo `provenance` presente in ogni preset rende esplicita questa origine.

Eventuali futuri importatori possono accettare soltanto template con licenza verificata e compatibile con redistribuzione e uso SaaS, per esempio MIT, Apache-2.0, BSD o CC0 quando applicabile. Prima dell'importazione vanno registrati almeno repository sorgente, autore, versione, licenza e file di attribuzione. Template proprietari, temi acquistati per singolo uso e contenuti ottenuti tramite scraping non devono entrare nel catalogo.
